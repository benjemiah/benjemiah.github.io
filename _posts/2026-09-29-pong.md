## Programming Pong in C with raylib!

![image](_images/codeblocks_29_09.png)
_i used Code::blocks, because its giving me less of a headache than vscode (but only for C!)_

Raylib is a C-library giving an abstraction layer to alot of stuff graphics-related. Its working on many platforms, so cross-compatibility is no problem. Instead of having to draw single pixels via some Hardware Abstraction Layer, you call basic functions creating pixels, objects (in 3D) or even Cameras!
I've also seen a video showing how importing maps based on Blender models is possible. Maybe i'll try that in my next iteration.

Coming back to Pong.
Pong is luckily a very easy game to program. You simply draw both paddles in a while loop, where everything gets refreshed (cleared) every iteration. By reading keyboard input and moving said paddles (and the ball) you produce movement.
For an electrical engineer, the process of polling the key inputs sounds really bad. In MCU/Embedded programming you really want to avoid that. But in software its different apparently.
For the ball, velocity in x and y direction has to be considered. When bouncing against paddels or walls, velocity switches sign. The rest is only polling position!
